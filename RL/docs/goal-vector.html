Goal-conditioned RL / 写経

写経で覚える目標ベクトル

1つの方策で3つの的を撃ち分ける。重みは一切変えずに、入力を1本書き換えるだけで。

所要 40〜60分 学習 3分 / CPU GPU 不要 MuJoCo 不要 pip install ×2

目標ベクトルとは何か

強化学習の方策は普通、観測から行動を決めます。この方策の「目的」は報酬関数に焼き付いていて、1つしかありません。的が3つあるなら方策も3本作る、というのが素朴なやり方です。

目標条件付けは、目的を入力に格上げします。

π(a | s)
観測 s から行動 a を決める。目的は1つに固定
π(a | s, z)
観測 s と「今回の目的」z から行動を決める。z を差し替えると振る舞いが変わる

この z が目標ベクトルです。実装上は本当にただの追加入力で、観測ベクトルの後ろに数値を何個か繋ぐだけ。今回は的が3つなので [1,0,0] [0,1,0] [0,0,1] という one-hot を使います。

なぜベクトルかというと、ニューラルネットの入力層に入る形が数値の並びしかないからです。それ以上の意味はありません。

要点はこれだけ

方策は1本のまま、目的を入力に格上げする。報酬関数はいじりません。目標条件付けは報酬設計の話ではなく、入力の話です。

STEP 00

環境を書く

平面上の点を動かして的に触りに行くだけの環境です。物理エンジンは使いません。毎エピソード、3つの的のどれか1つがランダムに「今回の目標」になります。ここが肝で、目標が固定ならそもそも z は要りません。

●reach_env.py
"""2次元リーチング環境。

エージェントは平面上の点。毎エピソード、3つの的のどれか1つが「今回の目標」になる。
goal_conditioned=False なら、観測は自分の位置だけ（＝目標が見えない）。
goal_conditioned=True なら、観測に目標ベクトル z（one-hot）が付く。
"""

import numpy as np
import gymnasium as gym
from gymnasium import spaces

# 3つの的。左・右・上。
TARGETS = np.array(
    [
        [-0.7, 0.0],  # 0: 左
        [0.7, 0.0],   # 1: 右
        [0.0, 0.7],   # 2: 上
    ],
    dtype=np.float32,
)
N_GOALS = len(TARGETS)


class ReachEnv(gym.Env):
    def __init__(self, goal_conditioned: bool, max_steps: int = 60):
        self.goal_conditioned = goal_conditioned
        self.max_steps = max_steps

        # 行動は2次元の速度指令。[-1, 1] に収める。
        self.action_space = spaces.Box(-1.0, 1.0, shape=(2,), dtype=np.float32)

        # ここが今回の主役。z を足すと観測が 2 次元から 2 + 3 次元になる。
        obs_dim = 2 + (N_GOALS if goal_conditioned else 0)
        self.observation_space = spaces.Box(
            -np.inf, np.inf, shape=(obs_dim,), dtype=np.float32
        )

    def _get_obs(self) -> np.ndarray:
        if not self.goal_conditioned:
            return self.pos.copy()
        z = np.zeros(N_GOALS, dtype=np.float32)
        z[self.goal_id] = 1.0  # ← 目標ベクトル
        return np.concatenate([self.pos, z]).astype(np.float32)

    def reset(self, *, seed=None, options=None):
        super().reset(seed=seed)
        self.pos = np.zeros(2, dtype=np.float32)  # 毎回原点から始める
        self.t = 0
        # options で目標を指定できる。指定がなければランダム。
        if options is not None and "goal_id" in options:
            self.goal_id = int(options["goal_id"])
        else:
            self.goal_id = int(self.np_random.integers(N_GOALS))
        return self._get_obs(), {}

    def step(self, action):
        a = np.clip(action, -1.0, 1.0).astype(np.float32)
        self.pos = np.clip(self.pos + 0.05 * a, -1.0, 1.0)
        self.t += 1

        dist = float(np.linalg.norm(self.pos - TARGETS[self.goal_id]))
        reward = -dist  # 目標に近いほど高い

        terminated = False
        truncated = self.t >= self.max_steps
        info = {"dist": dist, "goal_id": self.goal_id}
        return self._get_obs(), reward, terminated, truncated, info

見どころは2箇所だけです。

  • obs_dim = 2 + (N_GOALS if goal_conditioned else 0) — 観測が2次元か5次元かの分岐
  • z[self.goal_id] = 1.0 — 目標ベクトルを立てて、位置の後ろに繋ぐ

報酬は -dist のまま、両方の版で同じです。

STEP 01

z なしで学習して、失敗を見る

先に失敗を見ます。目標は毎回変わるのに、エージェントには見えない状態です。

●step1_plain.py
"""Step 1: 目標ベクトルなしで学習する（＝失敗を見る）。

目標は毎エピソード変わるのに、エージェントには見えない。
すると方策は「3つの的の真ん中あたり」に行くのが最善になる。どの的にも届かない。
"""

import numpy as np
from stable_baselines3 import PPO

from reach_env import ReachEnv, TARGETS, N_GOALS

TOTAL_TIMESTEPS = 150_000


def rollout(model, env, goal_id: int) -> np.ndarray:
    """指定した目標でエピソードを1本走らせ、最終位置を返す。"""
    obs, _ = env.reset(seed=0, options={"goal_id": goal_id})
    done = False
    while not done:
        action, _ = model.predict(obs, deterministic=True)
        obs, _, terminated, truncated, _ = env.step(action)
        done = terminated or truncated
    return env.pos.copy()


def main():
    env = ReachEnv(goal_conditioned=False)
    print(f"obs dim: {env.observation_space.shape[0]}  (position only)")

    model = PPO("MlpPolicy", env, verbose=0, seed=0)
    model.learn(total_timesteps=TOTAL_TIMESTEPS)
    model.save("ppo_plain")

    print("\n--- result ---")
    for goal_id in range(N_GOALS):
        final = rollout(model, env, goal_id)
        dist = np.linalg.norm(final - TARGETS[goal_id])
        print(
            f"goal {goal_id} {TARGETS[goal_id]} -> reached [{final[0]:+.2f} {final[1]:+.2f}]"
            f"  dist {dist:.3f}"
        )
    print("\nIf all three end up at the same spot, it failed exactly as intended.")


if __name__ == "__main__":
    main()

数値が多少ずれても構いません。3本が同じ場所に行っていれば再現できています。

STEP 02

z を足す

Step 1 との差分は goal_conditioned=True の1箇所だけ。アルゴリズムも学習量も報酬も変えません。

●step2_goal.py
"""Step 2: 観測に目標ベクトル z を足して学習する。

変えたのは env の引数 1つだけ。アルゴリズムも学習量も Step 1 と同じ。
"""

import numpy as np
from stable_baselines3 import PPO

from reach_env import ReachEnv, TARGETS, N_GOALS

TOTAL_TIMESTEPS = 150_000


def rollout(model, env, goal_id: int) -> np.ndarray:
    obs, _ = env.reset(seed=0, options={"goal_id": goal_id})
    done = False
    while not done:
        action, _ = model.predict(obs, deterministic=True)
        obs, _, terminated, truncated, _ = env.step(action)
        done = terminated or truncated
    return env.pos.copy()


def main():
    env = ReachEnv(goal_conditioned=True)  # ← 変えたのはここだけ
    print(f"obs dim: {env.observation_space.shape[0]}  (position 2 + goal vector 3)")

    model = PPO("MlpPolicy", env, verbose=0, seed=0)
    model.learn(total_timesteps=TOTAL_TIMESTEPS)
    model.save("ppo_goal")

    print("\n--- result ---")
    for goal_id in range(N_GOALS):
        final = rollout(model, env, goal_id)
        dist = np.linalg.norm(final - TARGETS[goal_id])
        print(
            f"goal {goal_id} {TARGETS[goal_id]} -> reached [{final[0]:+.2f} {final[1]:+.2f}]"
            f"  dist {dist:.3f}"
        )
    print("\nIf the three end up apart, each near its own target, it worked.")
    print("Saved the model to ppo_goal.zip")


if __name__ == "__main__":
    main()

方策は1本のままです。3本学習したのではありません。1つのネットワークが、入力に混ざった3つの数値を読んで行き先を変えています。

学習中に何が起きたかを言葉にすると、こうです。ランダムに振られた z と、その z に対応する報酬を大量に経験するうちに、方策が「z を読んで行動を変える」ことを覚えた。報酬関数は最初から最後まで -dist の一種類だけです。

STEP 03

重みを触らず z を差し替える

ここが本番です。学習済みの ppo_goal.zip を読み込んで、重みには一切触らずに z だけを操作します。

●step3_switch.py
"""Step 3: 学習済みの重みは一切さわらず、z だけを差し替える。

デモは2つ。
  A. 同じ位置で z だけ変えると、出てくる行動が変わる
  B. エピソードの途中で z を書き換えると、進路がその場で変わる（＝介入点）
"""

import numpy as np
from stable_baselines3 import PPO

from reach_env import ReachEnv, TARGETS, N_GOALS

LABELS = ["left", "right", "up"]


def make_obs(pos: np.ndarray, goal_id: int) -> np.ndarray:
    """位置と目標IDから観測を組み立てる。z は one-hot。"""
    z = np.zeros(N_GOALS, dtype=np.float32)
    z[goal_id] = 1.0
    return np.concatenate([pos, z]).astype(np.float32)


def demo_a(model):
    print("=== A. same position, different z ===")
    pos = np.zeros(2, dtype=np.float32)  # 原点に立たせる
    for goal_id in range(N_GOALS):
        obs = make_obs(pos, goal_id)
        action, _ = model.predict(obs, deterministic=True)
        print(
            f"z = {LABELS[goal_id]:<5}({make_obs(pos, goal_id)[2:].astype(int)})"
            f" -> action [{action[0]:+.2f} {action[1]:+.2f}]"
        )
    print("Only the three z entries changed. Same position, same weights.\n")


def demo_b(model, switch_at: int = 20, total: int = 60):
    print(f"=== B. swap z from left to right at step {switch_at} ===")
    env = ReachEnv(goal_conditioned=True, max_steps=total)
    obs, _ = env.reset(seed=0, options={"goal_id": 0})  # 左を目指して出発

    for t in range(total):
        if t == switch_at:
            env.goal_id = 1  # ← 介入。重みは触っていない
        action, _ = model.predict(obs, deterministic=True)
        obs, _, terminated, truncated, _ = env.step(action)
        if t % 10 == 0 or t == switch_at:
            mark = "  <- z swapped here" if t == switch_at else ""
            print(f"  t={t:2d}  x={env.pos[0]:+.2f}  y={env.pos[1]:+.2f}{mark}")
        if terminated or truncated:
            break

    print(f"  end   x={env.pos[0]:+.2f}  y={env.pos[1]:+.2f}")
    print("If x first moves negative and then turns back positive, it worked.")


def main():
    model = PPO.load("ppo_goal")
    demo_a(model)
    demo_b(model)


if __name__ == "__main__":
    main()

おまけ

図を描く

Step 1 と Step 2 を実行済みなら、冒頭の図が再現できます。pip install matplotlib が要ります。

●plot.py
"""おまけ: 2つの方策の軌跡を並べて描く。step1 と step2 を実行した後に走らせる。

図中のラベルは英語にしてある。matplotlib は既定で日本語フォントを持たず、
日本語を書くと豆腐（□）になるため。フォント設定に寄り道しないための割り切り。
"""

import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
from stable_baselines3 import PPO

from reach_env import ReachEnv, TARGETS, N_GOALS

COLORS = ["#c0392b", "#2471a3", "#1e8449"]
LABELS = ["left", "right", "up"]


def trajectory(model, goal_conditioned: bool, goal_id: int) -> np.ndarray:
    env = ReachEnv(goal_conditioned=goal_conditioned)
    obs, _ = env.reset(seed=0, options={"goal_id": goal_id})
    path = [env.pos.copy()]
    done = False
    while not done:
        action, _ = model.predict(obs, deterministic=True)
        obs, _, terminated, truncated, _ = env.step(action)
        path.append(env.pos.copy())
        done = terminated or truncated
    return np.array(path)


def draw(ax, model, goal_conditioned: bool, title: str):
    prefix = "z = " if goal_conditioned else "goal: "
    for goal_id in range(N_GOALS):
        path = trajectory(model, goal_conditioned, goal_id)
        # 太さを変えて描く。Step 1 では3本が完全に重なるので、
        # そのままだと最後の1本しか見えない。
        ax.plot(path[:, 0], path[:, 1], color=COLORS[goal_id], lw=6 - 2 * goal_id,
                alpha=0.9, label=f"{prefix}{LABELS[goal_id]}")
        ax.plot(path[-1, 0], path[-1, 1], "o", color=COLORS[goal_id], ms=7)
    for goal_id in range(N_GOALS):
        ax.plot(*TARGETS[goal_id], "x", color=COLORS[goal_id], ms=13, mew=3)
    ax.set_xlim(-1.0, 1.0)
    ax.set_ylim(-0.4, 1.0)
    ax.set_aspect("equal")
    ax.set_title(title)
    ax.grid(alpha=0.3)
    ax.legend(loc="lower right", fontsize=8)


def main():
    fig, axes = plt.subplots(1, 2, figsize=(11, 4.2))
    draw(axes[0], PPO.load("ppo_plain"), False,
         "Step 1: without z  (same spot for every goal)")
    draw(axes[1], PPO.load("ppo_goal"), True,
         "Step 2: with z  (one policy, three targets)")
    fig.tight_layout()
    fig.savefig("trajectories.png", dpi=140)
    print("wrote trajectories.png")


if __name__ == "__main__":
    main()

ここまでで手に入ったもの

書いたコードは実質3行

  1. 観測の次元を 2 から 2 + 3 にした
  2. z[goal_id] = 1.0 を立てて位置の後ろに繋いだ
  3. 推論時に z を指定した

これだけで、方策を再学習せずに実行中へ意図を差し込む口ができました。

ここが目標条件付けの本当の値打ちです。ニューラルネットの方策は普通、学習が終わったら中身に手が出せません。ビヘイビアツリーなら枝を差し替えられるのに、重みの塊にはその余地がない。z はその余地を作る仕掛けです。

そして z は「速い層と遅い層をつなぐ線」にもなります。方策は毎ステップ回さなければいけませんが、z を決める側は遅くて構いません。人が手で書いても、プランナが計算しても、LLMが数秒に1回更新してもいい。方策側から見れば、どれも同じ5次元の入力です。

次に触るなら

このチュートリアルは one-hot で止めました。自然な続きは3つあります。

z を連続値にする

TARGETS の3点をやめて、z に的の座標をそのまま入れます。学習時に的を平面上のランダムな点にすれば、学習中に一度も見ていない座標にも行けるようになります。one-hot では原理的に無理だったことです。

HER（Hindsight Experience Replay）

「的を外して別の場所に着いた」失敗軌跡を、「その着地点が目標だった成功例」として読み替えて再利用する手法です。報酬がまばらな設定で効きます。SB3 に HerReplayBuffer があるので、off-policy 系（SAC / TD3）に差し替えれば試せます。

z を埋め込みにする

文をエンコーダに通してベクトルにし、それを z に使います。ここまで来ると「言語で目標を指定する」形になります。

理論の背景をまとめて見るなら Goal-Conditioned Reinforcement Learning: Problems and Solutions（IJCAI 2022 サーベイ） が一望できます。原型は UVFA（2015）、実用化の鍵が HER（2017）です。

詰まったら

Step 1 で3本の到達点がバラけてしまう

学習が足りていない可能性があります。TOTAL_TIMESTEPS を 300_000 に増やしてください。逆に、たまたま似た場所に収束しているだけのこともあるので、seed を変えて数回試すと安定して観察できます。

Step 2 で的に届かない

goal_conditioned=True になっているか、表示された観測の次元が 5 になっているかを確認してください。2 のままなら引数が渡っていません。

Step 3 でモデルが読めない

ppo_goal.zip が同じディレクトリにあるか確認してください。Step 2 を実行すると作られます。

学習が遅い

TOTAL_TIMESTEPS を 50_000 まで落としても、Step 1 と Step 2 の差は見えます。精度は落ちますが、傾向の確認には足ります。

掲載した出力は、クリーンなディレクトリで通しで実行して再現を確認したものです（gymnasium 1.3.0 / stable-baselines3 2.9.0 / Python 3.11、CPUのみ）。
